# Privacy Policy — Kalender

Kalender is a Chrome extension that displays Google Calendar events.

## Data Access
Kalender accesses Google Calendar data using the Google Calendar API with read-only permissions.

## Data Usage
Calendar data is used only to display events within the extension interface.
No data is sold, shared, or transferred to third parties.

## Data Storage
Kalender does not store Google Calendar event data on external servers.
Only user preferences (such as selected calendars) are stored using Chrome storage.

## Authentication
Authentication is handled via Google OAuth using Chrome’s identity API.
Kalender does not store or have access to user passwords.
