# Contributing to Kalender Chrome Plugin

Contributions are welcome! 
& Design-only contributions are welcome!

## Guidelines
- Keep changes focused and well-described
- Prefer small, reviewable pull requests
- Ensure existing functionality continues to work


By contributing, you agree that your contributions will be licensed under the MIT License.

## Design & UX Contributions

Design improvements are especially welcome.

Areas that need the most attention:
- Visual clarity of the 12-month grid
- Event density handling (many events on one day)
- Multi-day event visualization
- Color usage and accessibility
- Overall polish and consistency

You can contribute by:
- Opening an issue with screenshots or mockups
- Proposing UI/UX changes before coding
- Improving CSS and layout structure
- Suggesting interaction patterns
